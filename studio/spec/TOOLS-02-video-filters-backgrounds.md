### 1.5 Application: WebGL2 3-D texture + hardware trilinear interpolation [observed]

`LutEffect` (module in `593.*.js`):

| Step | Detail |
|---|---|
| Fetch | `fetch(url, { signal: AbortSignal.timeout(15_000) })` — 15 s timeout constant `Duration.fromSeconds(15)` |
| Parse | Hand-written `.cube` parser; errors throw `CubeLutParseError` |
| Parser accepts | `TITLE` (ignored), `LUT_3D_SIZE` (must be integer >= 2), `DOMAIN_MIN` (must be all 0), `DOMAIN_MAX` (must be all 1) |
| Parser rejects | `LUT_1D_SIZE` -> `"1D LUTs are not supported"`; non-default domain -> `"only the default 0–1 domain is supported"`; row count != size³ -> `"expected N³ rows, got M"` |
| Comments | lines starting `#` and blank lines skipped |
| Storage | `Uint8Array(size³ * 4)`; each float clamped 0–1 then `Math.round(255 * v)`; alpha forced 255 -> **8-bit quantisation of the source floats** |
| GPU upload | `texImage3D(TEXTURE_3D, 0, RGBA, size,size,size, 0, RGBA, UNSIGNED_BYTE, data)` |
| Sampler state | `TEXTURE_WRAP_S/T/R = CLAMP_TO_EDGE`, `MIN/MAG_FILTER = LINEAR` (-> hardware trilinear) |

Fragment shader (module `10556`, verbatim, comments intact) [observed]:

```glsl
#version 300 es
precision highp float;
uniform sampler2D inputTexture;
// sampler3D has no default precision in ES 3.0 — the qualifier is mandatory
uniform mediump sampler3D lutTexture;
uniform float lutSize;
// 1.0 when sampling a top-row-first video upload, 0.0 for render-target input
uniform float flipY;
in vec2 v_uv;
out vec4 outColor;
void main() {
  vec2 uv = vec2(v_uv.x, mix(v_uv.y, 1.0 - v_uv.y, flipY));
  vec3 color = texture(inputTexture, uv).rgb;
  // Texel-center mapping: color 0 and 1 land on the centers of the first and
  // last lattice texels, so hardware trilinear interpolation never clamps.
  vec3 lutCoord = color * ((lutSize - 1.0) / lutSize) + 0.5 / lutSize;
  outColor = vec4(texture(lutTexture, lutCoord).rgb, 1.0);
}
```

Vertex shader (module `45242`): fullscreen triangle-strip quad, `v_uv = position*0.5+0.5`.

[all observed — sliders in `575.434695f973e2e774.js`, defaults in `UserCameraSettingsModel` in `593.*.js`]

They are only rendered when `shouldShowGreenScreenAdvancedSettings` is true, which is
`featureStore.advancedGreenScreen` <- URL param **`?advanced-green-screen`** (default **off**)

chroma-key path is active), because the uniforms live in the green-screen fragment shader.

**Value remapping before upload to the shader** (`GreenScreenEffect.render`) [observed]:

```js
const c = this.contrast   < 0 ? 1/(1 - this.contrast) : this.contrast + 1;  // -1..1 -> 0.5..2
const b = this.brightness / 2;                                             // -1..1 -> -0.5..0.5
const g = this.gamma      < 0 ? 1 - this.gamma        : 1/(this.gamma + 1); // -1..1 -> 2..0.5
uniforms.set("contrast", c); uniforms.set("brightness", b); uniforms.set("gamma", g);
```

Shader application: `pow(rgb, vec3(gamma)) * contrast + brightness` [observed].

### 3.3 `MediapipeRenderer` — blur vs. background replace

`FxType = { Blur:0, Background:1 }` [observed]. Set through
`MediapipeBackgroundEffect.setBackground({ fxType, image? })`.

| Constant | Value | Meaning |
|---|---|---|
| Render-pass scale `x` | **0.5** | mask-filter and both blur passes run at **half** the drawing-buffer size |
| Blur render targets | **2** (`blurRenderPasses[0..1]`) | horizontal then vertical pass |
| Mask filter target | 1 (`maskFilterPass`) | bilateral mask cleanup, background mode only |

**Blur path** (`drawBlur`) [observed]: pass 1 horizontal -> pass 2 vertical -> composite.
`texelSize = [1/blurTarget.width, 1/blurTarget.height]`.

Blur fragment shader (module `13134`, verbatim comments) [observed]:

```glsl
uniform sampler2D u_videoTex, u_maskTex;
uniform float u_firstPass;   // 1.0 on first pass, 0.0 on second pass
uniform vec2  u_texelSize;
const float weights[] = float[](0.882496903, 0.60653066, 0.324652467, 0.135335283);
// "fixed 9x9 gaussian blur over the video texture with sigma = 2.0 ... 2 passes ...
//  We use the mask to tweak the blur radius and eliminate the foreground texels
//  to prevent halo"
vec2 step = (1.0 - texture(u_maskTex, v_texCoord).r) * u_texelSize * vec2(u_firstPass, 1.0-u_firstPass);
```

* **Blur radius is NOT user-adjustable.** It is a fixed 9x9 kernel, sigma = 2.0, and the
  *effective* radius is modulated **per pixel by (1 - mask)** so foreground pixels contribute a
  zero step. There is no blur-strength slider anywhere in the UI. [observed]
* Kernel taps: centre weight 1.0 implicit + 4 symmetric taps per axis.

**Background-replace path** (`drawBackground`) [observed]: mask-filter pass -> composite.

Mask filter shader (module `30664`) — a **joint bilateral filter** used as edge
smoothing/feathering [observed]:

```glsl
const float weights[] = float[](0.60653066, 0.882496903, 1.0, 0.882496903, 0.60653066); // sigma = 2.0
const float offsets[] = float[](-2.0, -1.0, 0.0, 1.0, 2.0);                             // 5x5 window
const float colorSigmaCoeff = 200.0; // sigma = 0.05  (colour-range term)
weight *= exp(-colorSigmaCoeff * dot(colorDiff, colorDiff));
...
totalMask /= totalWeight;
totalMask = pow(totalMask, 1.5);   // gamma-shapes the alpha edge
outColor = vec4(totalMask);
```

| Edge-smoothing parameter | Value | User-adjustable? |
|---|---|---|
| Spatial kernel | 5x5, sigma = 2.0 | No |
| Colour-range sigma | 0.05 (`colorSigmaCoeff = 200.0`) | No |
| Alpha shaping exponent | **1.5** | No |
| Filter resolution | 0.5 x drawing buffer | No |

Composite shader (module `42938`) [observed]:

```glsl
vec3 backgroundColor = texture(u_backgroundTex, uv).rgb;
backgroundColor += 0.02 * mask * videoColor;   // 2% subject spill onto the plate
outColor = vec4(mix(backgroundColor, videoColor, mask), 1.0);
```

Vertex shader for all three (module `85877`): `layout(location = 0) in vec2 a_position;`.

### 4.3 Algorithm (verbatim shader, module `30668`) [observed]

```glsl
// From https://github.com/libretro/glsl-shaders/blob/master/nnedi3/shaders/rgb-to-yuv.glsl
vec2 RGBtoUV(vec3 rgb) {
  return vec2(rgb.r*-0.169 + rgb.g*-0.331 + rgb.b* 0.5   + 0.5,
              rgb.r* 0.5   + rgb.g*-0.419 + rgb.b*-0.081 + 0.5);
}
float chromaDistance = distance(RGBtoUV(input.rgb), RGBtoUV(keyColor));
float baseMask = chromaDistance - similarity;
float fullMask = pow(clamp(baseMask / smoothness, 0., 1.), 1.5);   // alpha
float spillVal = pow(clamp(baseMask / spill,      0., 1.), 1.5);   // spill suppression
float desat = clamp(r*0.2126 + g*0.7152 + b*0.0722, 0., 1.);       // Rec.709 luma
rgb = mix(vec3(desat), rgb, spillVal);                             // desaturate spill fringe
rgb = mix(backgroundImageRgba, rgb, fullMask);                     // composite
return vec4(pow(rgb, vec3(gamma)) * contrast + brightness, a);     // CalcColor
```

Key points [observed]:
* Keying is in **UV (chroma) space**, luma-independent.
* Both mask and spill use the same `baseMask`, shaped with exponent **1.5**.
* **Spill suppression = desaturate toward Rec.709 luma**, weighted by `spillVal`.
* Default background when none selected: `new ImageData(Uint8ClampedArray([0,0,0,255]),1,1)` —
  a 1x1 opaque **black** pixel.
* Textures uploaded as `internalFormat: RGB, format: RGB`.
* Uniform type map: `{inputTexture:sampler2D, inputTextureWidth:float, inputTextureHeight:float,
  keyColor:vec3, similarity:float, smoothness:float, spill:float, contrast:float,
  brightness:float, gamma:float, backgroundImageTexture:sampler2D}`.

## 5. Beautify / "Touch up appearance" (skin smoothing) — the 4th effect

Not named in the task brief but it is a first-class video filter; catalogued here in full.

### 5.1 Parameters — names, ranges, defaults [observed]

Defaults object (`593.*.js`, module `80393`, export `Gj`), slider bounds (export `hp`) and UI:

| Parameter | UI label | UI title | min | max | step | **Default** |
|---|---|---|---|---|---|---|
| `intensity` | (unlabelled slider next to toggle) | Touch up intensity | **0.2** | **0.6** | **0.1** | **0.3** |
| `radius` | Smoothing radius | Beautify smoothing radius | 0.2 | 2 | 0.05 | **0.6** |
| `detail` | Detail | Beautify detail preservation | 0 | 1 | 0.01 | **0.4** |
| `edgeThreshold` | Edge threshold | Beautify edge threshold | 0 | 0.1 | 0.005 | **0.015** |
| `edgeSoftness` | Edge softness | Beautify edge softness | 0.01 | 0.5 | 0.01 | **0.15** |
| `textureProtection` | Texture protection | Beautify texture protection | 0 | 1 | 0.01 | **0.6** |
| `maskThreshold` | Mask threshold | Beautify mask threshold | 0 | 0.9 | 0.01 | **0.4** |
| `maskFeather` | Mask feather | Beautify mask feather | 0.05 | 0.6 | 0.01 | **0.25** |

Only `intensity` is persisted (`studio.settings.beautifyFilterIntensity`, clamped codec
`BoundedNumber(0.2, 0.6)`); the other seven are in-memory `beautifyFilterTuning` and reset on
reload [observed]. Toggle key: `studio.settings.isBeautifyFilterEnabled`, default **false**.
Element ids: `liveStudioBeautifyToggle`, `liveStudioBeautifyIntensity`,
`liveStudioBeautify-radius`, `-detail`, `-edgeThreshold`, `-edgeSoftness`,
`-textureProtection`, `-maskThreshold`, `-maskFeather`. Reset button: **"Reset to defaults"**.
Toggle copy: **"Touch up appearance"** + badge **"NEW"**, info
**"Smooth skin while keeping its natural texture."**

Derived uniform mapping in `render()` [observed]:

```js
strength  = maskUploaded ? intensity : 0;
edgeLow   = edgeThreshold;
edgeHigh  = edgeThreshold + max(edgeSoftness, 0.001);
maskLow   = min(maskThreshold, 0.99);
maskHigh  = min(maskLow + max(maskFeather, 0.001), 1);
texelStep = [radius / statsWidth, 0]  then  [0, radius / statsHeight];
inputTexelSize = [1/width, 1/height];
```

### 5.2 Three-pass GPU implementation [observed]

| Pass | Shader module | Purpose | Resolution |
|---|---|---|---|
| downsample | `28588` | mask-premultiplied colour: `vec4(color*mask, mask)` | **0.25 x** input |
| blur (x2) | `99231` | 9-tap box blur along one axis (`for i=-4..4`, `/9.0`) | 0.25 x input |
| combine | `81285` | edge-aware smoothing + high-pass detail re-add | full res |

Combine shader highlights (verbatim comments preserved in the bundle) [observed]:

```glsl
const vec3 LUMA = vec3(0.299, 0.587, 0.114);
mask  = smoothstep(maskLow, maskHigh, mask);
vec3 mean = stats.rgb / max(stats.a, 0.02);          // normalized skin-only mean
// 3x3 binomial high-pass  (0.25 centre, 0.125 edge, 0.0625 corner)
vec3 highPass = color - blur3;
float edge = abs(dot(color, LUMA) - dot(mean, LUMA));
float k = (1.0 - smoothstep(edgeLow, edgeHigh, edge)) * mask * strength;
float grain = dot(abs(highPass), LUMA);
k *= 1.0 - textureProtection * smoothstep(0.02, 0.08, grain);   // beard/brow guard
vec3 smoothed = mix(color, mean, k);
outColor = vec4(smoothed + detail * k * highPass, 1.0);
```

Vertex shader `13780` uses `layout(location = 0) in vec2 position;` — "three programs share one
VAO, so the attribute must resolve to the same slot in every one of them" [observed comment].
Mask texture is `R8` / `RED` / `UNSIGNED_BYTE` with `UNPACK_ALIGNMENT` toggled 1 -> 4 [observed].

### 6.2 Crop / fit / gravity — layout engine, not the video pipeline [observed]

`externals.b634d3e8690cf1f3.js` (`@restream` layout runtime) defines `ElementLayoutV2`:

```ts
FitType = { Cover:"Cover", Contain:"Contain" }
Gravity = { TopLeft, TopCenter, TopRight,
            CenterLeft, CenterCenter, CenterRight,
            BottomLeft, BottomCenter, BottomRight }
ElementLayoutV2 = { meta:{shouldShowShadow, shouldRoundCorners, sourceWidth, sourceHeight,
                          sourceVideoUrl?, staticImageUrl?},
                    background: ARGB, fit:{type, gravity},
                    cropContainer:{left,top,width,height},   // Int
                    videoContainer:{left,top,width,height},  // Int
                    opacity:Int, zOrder:Int, borderRadius:Int }
```

* Per-tile fit is **auto-chosen** (`Cover` when the source aspect is close enough to the slot,
  else `Contain`) and can be overridden per layout via `getFitType` / `getFitGravity`, default
  gravity `CenterCenter` [observed].
* Rendered as `objectFit: fit.type === Contain ? "contain" : "cover"` [observed].
* `cropContainer` is always emitted as `left:0, top:0, width:slotW, height:slotH` at the sites
  inspected — i.e. **no free-form crop rectangle UI** [observed at three call sites].
* **There is no per-tile zoom or pan control.** The only `zoomLevel` in the codebase belongs to
  `UserScreenShareModel` and is the browser **Captured Surface Control** API for zooming a
  shared *tab* (`getSupportedZoomLevels()`, `increaseZoomLevel()`, `decreaseZoomLevel()`,
  `resetZoom()`, default `100`) — not a camera transform [observed].
* Layout types (compositor level, for context): `SPOTLIGHT`, `PADDED_SPOTLIGHT`, `AUTO_CONTAIN`,
  `AUTO_COVER`, `HALF_SCREEN`, `CINEMA`, `THUMBNAILS`, `PICTURE_IN_PICTURE`, `Showtime`
  [observed].
